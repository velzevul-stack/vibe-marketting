Пакет для сценария **получения API** (Playwright → Telegram Web → my.telegram.org).

- **Инструкция для чата (копипаст):** [CHAT_INSTRUCTION_RU.md](CHAT_INSTRUCTION_RU.md)

Прокси и сессии в репозиторий не кладутся. На сервере: **`config/proxies.txt`**, сессии — импорт **`accounts.zip`** (меню **9 → 1**) или распаковка в каталог из **`telethon_session_dir`** в `settings.json`. Имена вида **`+123456789012.session`** поддерживаются.
